Choose Your Second Factor
Rule of thumb: any MFA is better than none — even SMS codes stop the vast majority of automated account takeovers. Upgrade to an authenticator app or hardware key when you can, especially for email, banking, and any account used to recover others.
Check a Password Against Known Breaches
This is a real, safe check. Your password never leaves your device. We hash it (SHA-1), send only the first 5 characters of that hash to the Have I Been Pwned API, and check the returned list locally. This is called k-anonymity — the same privacy trick used by real security tools.
🔒 Tip: use a fake or old password here to try it — never test a password you're currently using anywhere, even though this check is safe.
